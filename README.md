# Nature Adventure — Retail Camping Company Website

> **Status: Complete.** A static website built as coursework in 2023.

A multi-page static website for a fictional retail camping company, built with plain HTML and CSS as a static web development assignment (SFU).

## Pages

- `index.html` — homepage
- `aboutus.html` — about the company
- `products.html` — product catalogue
- `interproduct.html` — individual product detail page
- `offers.html` — promotions/offers
- `reviews.html` — customer reviews
- `cart.html` — shopping cart mockup
- `contactus.html` — contact page

## Tech stack

- **HTML** — page structure
- **CSS** — styling (`css/style.css`)
- No JavaScript or backend — this is a static-only site; the cart and forms are visual mockups, not functional.

## Setup

No build step required. Open `index.html` directly in a browser.

## Notes

This was built as a static web development assignment — the focus was on HTML/CSS layout and styling, not interactivity or a backend. The cart, offers, and reviews pages display static content rather than live data.
